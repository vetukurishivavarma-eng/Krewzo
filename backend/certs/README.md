# UIDAI certificates

Put UIDAI's production certificate for **Aadhaar Paperless Offline e-KYC / Secure QR** here (`.cer`, `.crt` or `.pem`).
Download it from uidai.gov.in -> Ecosystem -> Developer section -> Data and Downloads -> UIDAI certificate details.
It is a public certificate, safe to commit. Without one, every ID check is flagged "signature not checked" and waits for manual review.
