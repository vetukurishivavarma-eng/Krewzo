Installing on Android

  1. Download and open the file

    Tap a download button above, or scan its QR code with the phone camera, then open the downloaded file.

  2. Allow installs from this source

    Android asks once. Tap Settings, turn on Allow from this source, then go back.

  3. Tap Install anyway

    Play Protect may call the app unrecognised because it is not on the Play Store yet. Tap More details, then Install anyway.

  4. Allow notifications

    Krewzo asks on first launch. Workers should also turn on the pop-up and full-screen alert from the Partner home screen.
